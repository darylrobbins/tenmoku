# Publish a Tenmoku language pack with each grammar release: one tarball of the eight extension directories ready to unpack into the extensions directory, with its checksum and install notes (Mac T1323)

Card 6 of docs/grammar-size-audit/README.md (offline users). Builds on T1304/T1305's scripts/build-grammar-wasm.sh output in target/grammar-wasm/ and on the fetch/install card, whose directory layout (<extensions dir>/tenmoku.grammar_<lang>/) the pack reproduces.

Design calls (record in docs/decisions/<lane>-*.md):
1. Built by .github/workflows/grammars.yml, not release.yml as the README says: that workflow already has the eight wasm in hand on the grammar tag, and release.yml is a macOS app build with no wasi-sdk. This avoids a second wasm build whose hashes could differ from pack.toml's.
2. Format: .tar.gz of the eight extension directories (Finder, Linux and WSL all open it; no zip dependency), so "install" is unpacking into the user extensions directory, and the loader's watcher picks it up without a restart.
3. No in-app pack UI in this card. The fetch card's installer can already install from an unpacked pack directory with hash verification; the failure toast of the banner card points offline users at the docs page.
4. Test inputs are stub wasm files generated by the test; no real wasm and no wasi-sdk, so it runs on helium. The script takes GRAMMAR_WASM_DIR (default target/grammar-wasm) and DIST_DIR (default dist) for that, and guards sha256sum/shasum with command -v.
