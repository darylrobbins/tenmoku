## New

- Dock panels can be split into groups: drag a tool tab to the edge of a group to open side-by-side groups, each with its own tab strip and active panel. Tabs can be reordered within a strip, and groups have a draggable divider, can be hidden individually, disappear when emptied, and are saved and restored with your layout. In the bottom panel you can drag the Git log beside the terminal, and Split Panel Right, Move Tool Window to Next or Previous Group, Join Panel Groups and Focus Next Panel Group are in the command palette. Vim's `<C-w>h` and `<C-w>l` move between groups.
- A What's New tab shows the release notes once, on the first launch after an update. Reopen it any time from Help > What's New or the command palette.
- Run Task detects Python projects: the main file, `[project.scripts]` entries, pytest, and `uv run` when the project uses uv.
- A read-only hex viewer opens binary files as offset, hex and ASCII rows. It supports Open as Hex, go to offset, find by hex or text, and copy as hex or text (Ctrl+F and Ctrl+C on Linux). Binary files open in it by default. A byte inspector under the rows shows the selection as 8- to 64-bit integers and 32- or 64-bit floats, little or big endian.
- Move to New Window, from a file tab's pane menu, moves the file into a new window. A binary file opens there in the hex viewer, and a window you have already used is kept if the file fails to load.
- Completion as you type: suggestions appear after a short pause, stay quiet in comments and strings, and no longer steal Enter. When no language server answers, words from open files are suggested instead.
- Tenmoku offers to install a missing language or its language pack from the verified registry the first time you open a file, with Not now and Don't ask again choices. Open editors are re-highlighted once it installs.
- Syntax highlighting for WebAssembly text (.wat, .wast), WIT (.wit) and Fluent (.ftl) files.
- Build Project runs cargo as a Build Run in the Runs panel and sends compiler messages to the Problems panel.
- Build run detail shows a crate-by-crate waterfall (fresh, rebuilt and local crates) with a Timeline or Output view.
- The Debug Console shows adapter output by category and has an input with history and expandable results.
- While stopped in the debugger, hovering an expression shows its evaluated value.
- The editor context menu adds Code Actions when the language server offers some at the cursor, plus Run Test, Toggle Breakpoint, Git Blame and Ask Agent.

## Improved

- Italic and bold syntax styles are now drawn in the editor, and function names are bold at their definition. Spline Sans Mono now ships Italic and Bold Italic faces.
- Markdown and other markup are styled as you write: **strong** text is bold, *emphasis* italic, ~~strike~~ struck through and headings bold, with quotes and list markers coloured. Rust doc comments get the same styling. Symbols your language server marks deprecated are struck through.
- The Terminal panel shows a single header row when one terminal is open. The dock strip carries New Terminal and Close, and the session tab row appears from two terminals.
- The LazyVim preset includes LazyVim's `<leader>d` debug keys.
- Peek Definition and Peek References draw a thin neutral border in every theme instead of a thick accent one.
- Expanded commits in the Git log graph indent their file rows so files read apart from commits.
- rust-analyzer starts with memory-conscious defaults: nested git worktrees and `target/` are excluded, and cache priming and cache size are tuned. Your own initialization options still take precedence.

## Fixed

- The breakpoint menu takes its own focus, so an input method composing in the editor can no longer commit text or take the arrow keys while it is open.
- A stray "by language server" label no longer appears in the status bar.
- With no folder open, the Project sidebar offers an Open Folder… button, and its + opens a menu instead of doing nothing. The + is now labelled Add to Project.
- Language Server Log for a server that never started opens a read-only log tab with the server's status (for example "pyright not found") instead of an empty, editable untitled tab.
