## New

- **Python files now use pyrefly by default, instead of pyright.** Choose the server with `lsp.python_server`: `"pyrefly"` (the default), `"ty"` or `"pyright"`. To keep pyright, set `python_server = "pyright"` under `[lsp]` in your settings. Only the chosen server runs. When it isn't installed, the status item names the missing program and how to install it (for example `pip install pyrefly`).
- ruff's language server runs alongside the Python server when it's installed, adding its lints, formatting and code actions.
- Python language servers use the project's virtual environment: `$VIRTUAL_ENV`, else the project's `.venv` or `venv`, or the one `[lsp] python_environment` names. A server installed in that environment is found even when it isn't on your PATH, and it's given the environment's interpreter.
- File > Close Folder returns the window to the Start page. The folder's language servers and file watchers stop, and the next launch doesn't reopen it.
- Move a tool window between the bottom panel and the sidebar: drag its tab onto the sidebar or rail, drag a rail button onto the bottom panel, or use Move Tool Window to Sidebar / Bottom Panel. The rail follows where each tool lives, and the placement is saved with the window layout.
- PDFs open in a "This is a PDF" view with Open in Default App and Open as Hex, instead of as text or hex.
- Test code lenses show how a test has done lately, for example "passed in the last 8 runs", from the test history.

## Improved

- Files with an unknown extension get their language from the first line and the content (`<?php`, HTML markup, XML or JSON). A language chosen with Change Language Mode is remembered for that file; Auto Detect clears it.
- A file's menu in the project tree has Open and Open to the Side, so you can open a file in a split to the right.
- The project tree's New menu opens from the keyboard (Cmd-N in the tree on macOS, Alt-N elsewhere), and New File and New Folder have keys outside vim mode.

## Fixed

- The hex viewer's byte inspector keeps a long value's tooltip inside the window, scrolling when it's taller than the window.
